📡 GitHub Pages + Google Sheets로 운영하기

GitHub Pages: 이 HTML 파일을 GitHub repo에 올리면 모든 사용자가 URL로 접속할 수 있습니다.

  1. GitHub에서 새 repo 생성 (예: golsabumo)
  2. 이 HTML 파일을 index.html로 업로드
  3. Settings → Pages → Source를 main으로 설정
  4. https://[username].github.io/golsabumo/ 으로 접속 가능!

📡 실시간 동기화

관리자가 설정한 동기화가 활성화되어 있습니다.

GitHub repo에 data.json으로 자동 저장됩니다. 일반 회원은 로그인만 하면 자동으로 동기화됩니다.

설정 가이드
1. GitHub Fine-grained token 생성 (No expiration)
2. Repository: golsa 선택 → Contents: Read and write
3. 토큰/사용자명/repo 입력 → "업로드"
4. 자동 동기화 15~30초 설정
5. 회원들은 로그인만 하면 자동 동기화!
